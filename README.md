# NetWatch

NetWatch is a Dockerised network monitoring and observability platform.

The project is designed to run on a Raspberry Pi as an always-on
home network monitoring server, while being developed locally on
Apple Silicon Macs.

## Planned Features

- Network device discovery
- Device availability monitoring
- Ping and latency monitoring
- Internet performance monitoring
- DNS monitoring
- Pi-hole integration
- Historical network analytics
- Network topology
- Alerts and notifications
- Docker monitoring
- REST API
- LLM-powered network assistant
- Raspberry Pi deployment

## Technology

- Python
- Django
- PostgreSQL
- Redis
- Celery
- Docker
- Docker Compose
- JavaScript
- HTML/CSS
- REST APIs
- Raspberry Pi
- LLM integration
